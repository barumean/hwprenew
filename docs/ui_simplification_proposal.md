# 직관적인 사용 인터페이스 개선안

> [!NOTE]
> **상태: 반영 완료.** `작업창.py`가 통합 UI로 확정되었습니다. 이에 맞춰 `표정리.py`에 중복으로 있던 내장 실행 창(run_gui)은 제거했고, `표정리.py`를 인자 없이 실행(더블클릭)하면 `작업창.py`로 연결됩니다. `표정리.py`는 처리 엔진 겸 명령줄 도구로 남습니다.

## 결론

현재 프로그램은 기능은 충분하지만 사용 흐름이 개발자 친화적입니다. 일반 사용자는 콘솔 로그, 파일 선택 후 대기, 오류 메시지를 해석하는 과정에서 부담을 느낄 수 있습니다. 가장 현실적인 개선은 기존 `표정리.py` 처리 로직은 유지하고, 그 위에 얇은 GUI 작업창을 추가하는 방식입니다.

이번 검토에서는 별도 작업창 실행 파일 `작업창.py`를 추가했습니다. 이 방식은 핵심 처리 로직을 크게 건드리지 않아 안정성을 유지하면서도 사용자는 버튼 중심으로 실행할 수 있습니다.

## 추천 사용 흐름

1. `python 작업창.py` 실행
2. [파일 선택]으로 HWP/HWPX 선택
3. 필요하면 [서식 설정]에서 표/그림틀/사진/공통 규칙 확인 또는 수정
4. [정리 시작] 클릭
5. 작업 로그를 창 안에서 확인
6. 완료 후 [결과 폴더 열기]로 `_정리본` 파일 확인

## 인터페이스 대안 비교

| 대안 | 장점 | 단점 | 추천도 |
|---|---|---|---|
| Tkinter 작업창 | Python 기본 GUI라 추가 의존성이 없고 배포가 쉽습니다. | 디자인 자유도는 낮습니다. | 높음 |
| 웹 UI(로컬 서버) | 화면 구성이 예쁘고 확장성이 좋습니다. | 서버 실행, 브라우저, 보안/포트 이슈가 생깁니다. | 중간 |
| EXE 패키징 | 더블클릭 사용성이 가장 좋습니다. | PyInstaller 설정과 백신 오탐 대응이 필요합니다. | 중간 |
| 한글 내부 매크로/리본 | 사용자 경험이 자연스럽습니다. | 한글 버전별 호환성과 배포 난도가 큽니다. | 낮음 |

## 이번에 반영한 작업창 기능

- 파일 선택 버튼
- 서식 설정 버튼: 표/그림틀/사진/공통 설정을 작업창에서 폼으로 편집
- 정리 시작 버튼
- 실시간 작업 로그 표시
- 진행 중 상태 표시
- 완료 후 결과 폴더 열기 버튼
- 원본 보호 흐름 유지: 기존과 동일하게 `_정리본` 파일 생성

## 추가로 권장하는 개선

### 1. 설정 프리셋 선택

이번 변경으로 작업창에서 주요 설정을 직접 편집할 수 있게 되었습니다. 다음 단계로는 `기본`, `엄격`, `그림틀만`, `너비 유지` 같은 프리셋을 선택할 수 있게 하면 반복 설정이 더 쉬워집니다.

### 2. 검사 전용 버튼

실제 저장 전 표 개수, 그림틀 수, 사진 수, 적용 예정 규칙을 보여주는 [검사만 실행] 버튼을 추가하면 안전합니다.

### 3. 결과 요약 카드

완료 후 다음 내용을 창 상단에 요약하면 비전문 사용자에게 더 직관적입니다.

- 정리한 표 수
- 그림틀 수
- 사진 속성 변경 수
- 실패 수
- 저장 위치

### 4. 오류 해결 가이드 연결

오류 발생 시 단순 로그 대신 다음 안내를 함께 보여주면 좋습니다.

- 한글이 설치되어 있는지 확인
- 문서가 암호/배포용인지 확인
- 다른 한글 프로세스가 파일을 잠그고 있는지 확인
- 진단용 `python 표정리.py --보기 문서.hwp` 실행

## 충돌 확인 결과

이 문서는 작업창 GUI 설명과 서식 설정 GUI 설명을 함께 유지하는 방향으로 정리했습니다. Git 충돌 표식이 남아 있지 않은 상태를 확인했습니다.

## 구현 방향

단기적으로는 `작업창.py`를 유지하면서 `표정리.py`는 CLI/처리 엔진으로 두는 구조가 가장 안전합니다. 설정은 작업창에서 `서식규칙.yaml`을 읽고 저장하는 방식으로 연결해 비개발자도 YAML을 직접 열지 않고 사용할 수 있습니다. 장기적으로는 처리 결과를 구조화된 JSON으로 반환하게 만들어 작업창이 콘솔 문장을 해석하지 않고 정확한 결과 요약을 보여주도록 개선하는 것이 좋습니다.
